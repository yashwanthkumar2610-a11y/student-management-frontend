Student Management System — Frontend

A web-based Student Management System built using React and Vite. It connects to a Node.js backend and MySQL database to manage student records.

Technologies Used

- React
- Vite
- JavaScript
- CSS
- Axios

Features

- Add student records
- View the student list
- Edit student details
- Delete student records
- Connect to the backend API

Run Locally

1. Install Node.js.
2. Clone or download this repository.
3. Open a terminal in the frontend folder.
4. Run "npm install".
5. Run "npm run dev".
6. Open the local URL displayed in the terminal, usually "http://localhost:5173".

Project Status

Core student management features are implemented and tested locally.

Note: The backend and MySQL database must also be running for student data operations to work.
